Krafty Manual

Head Checker

Report what can be checked automatically, including a viewport that asks the browser not to zoom. Preview how the page appears in search results and when shared, and list every value in the head.

Nest Checker

Highlight elements that their parent element is not allowed to contain, explain each one on hover, and count them by kind.

Heading Checker

Report what can be checked automatically about the heading structure, and list the headings as an indented outline for you to read. Hover a row to box the heading on the page and click to scroll to it.

Markup Checker

Report markup that is wrong in ways the page does not show: ids used more than once, tables with no header cells, form fields and links and buttons with nothing naming them, iframes and embeds with nothing naming them, inline SVGs that are neither named nor hidden, and contradictions in a page's ARIA. Also a form button with no type when it is not the only submitter, a label whose for points nowhere, and videos with no caption track — that last one listed rather than asserted, because burned-in captions leave no element. Hover a finding to box an element on the page and click to scroll to it — aggregate findings point at the first instance.

Image Checker

Find images — including CSS background-image — served much larger than the space they are shown in, and images with no width and height attributes — both listed so you can point at them on the page. Allows for high-density displays, so a correctly built retina image is not reported.

Leftovers Checker

Find development leftovers a page shipped with: resources pointing at a local or private address no visitor can reach, http resources on an https page that the browser blocks, images still coming from a placeholder service, and — listed rather than asserted — staging-looking hosts, developer markers left in HTML comments, and dummy or placeholder text left in the visible copy.

Landmark Checker

Report what can be decided about a page's landmark regions — a missing or duplicated main, and landmarks of one role a screen reader cannot tell apart — and draw the landmarks nested, each with its role and name, for you to read as a map of the page. Hover a row to box the region on the page and click to scroll to it.

Token Check

List the colours, fonts, border radii and box shadows the page actually renders with, led by counts that show whether the tokens look disciplined. Near-identical values and a typeface that never loaded are noted for you to judge — Krafty does not know the design system, so it does not assert off-system.

Tab Checker

List every control Tab reaches, in that order, with its role and name. Whether the order matches the page is for you to read. Hover a row to box the control and click to scroll to it.

Target Checker

List buttons and links whose box is smaller than 24 CSS pixels on a side, with the measured size. Inline links in a sentence are left out, and the size is not a verdict — space around a control can still make it fine.

Outline Checker

Display an outline around every element.

Alt Checker

Display the alt attribute of every image, and flag images whose alt is missing or empty. Labels are placed by measurement and re-measured when images load or enter view; use Check again after a reflow the automatic pass misses.

Brightness Checker

Make the page monochrome.

Squint Checker

Blur the page until the text can no longer be read, so what stands out first — and whether the main action is it — can be judged without the words. Combine with Brightness to squint in monochrome.

Spacing Checker

Widen line, letter, word and paragraph spacing to the point where a reader's own stylesheet would, so clipping and overlap can be seen. Krafty does not count them.

Dummy Checker

Swap text, field values and pictures for stand-ins of a similar size, so a screenshot does not carry a name, a line or a picture you did not mean to share. Spaces stay, and wide characters stay wide, so the lines wrap where they did. Canvas, video and a frame Krafty cannot open are covered with a labelled patch of the same size, because those pixels cannot be edited. An inline drawing is left as it is. Turn it off before sending a form: the fields hold stand-ins until you do, and then the page is as it was. Krafty does not count any of this.

Keyboard shortcuts

Every checker can be toggled from the keyboard, but none come with a key already assigned. Pick your own here:

chrome://extensions/shortcuts

Krafty ships no default keys on purpose. Chrome drops a suggested key that anything else already claims, and does so without an error anywhere, so a default that looks reasonable can simply never work and leave the feature looking broken. Choosing your own takes a moment and always works.
